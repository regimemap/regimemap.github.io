Use cases

Where it fits

Four kinds of page, each with the embed set up the way that page needs. The pages are mockups made for this site; desktop on the left, phone on the right.

Law-firm blog

A firm explains, in an article, where online casino can be licensed. The map sits between paragraphs, with the credit line under it in the blog’s own serif.

  • map
  • script
  • light

Compliance newsletter

A compliance team’s newsletter archive runs in dark mode. The embed follows with data-theme="dark".

  • map
  • script
  • dark

News article

A news site that strips scripts uses the iframe form. Readers see the same map.

  • map
  • iframe

Practice page

A firm’s Japan practice page shows one country card beside its text, including the lawful exception for pachinko halls.
