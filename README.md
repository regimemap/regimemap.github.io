# regimemap.github.io

The home of the free [Regime Map](https://regimemap.com/) embeds: a world map of gambling regulation for five products and a country card, for any website.

- Site: https://regimemap.github.io/
- Configurator: https://regimemap.github.io/configurator/
- Code examples: https://github.com/regimemap/regimemap-embed-examples

Static HTML, one stylesheet, two small scripts. No build step, no cookies, nothing loaded from other websites except the embeds from regimemap.com.

Not legal advice: the embeds show Regime Map's editorial reading of official sources on the date shown.
